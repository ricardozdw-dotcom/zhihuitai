# 知汇台前端

React + TypeScript + Vite + Ant Design。保留原型演示模式，也支持真实后端模式。

## 运行

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:43123>。在 `.env.local` 设置 `VITE_USE_API=true` 启用 API；`/api` 由 Vite 代理到本机 43180。未设置时使用演示数据。角色选择只控制视图，不是登录与鉴权。

## 已连接后端的页面

- 知识库与文件导入：`/#/knowledge`。导入为“选择文件 → 解析、分块与索引预览 → 确认”三步；本轮未扩展后端分块策略，后端仍使用已有分块配置。
- 在线对话：`/#/chat`，SSE 返回真实检索引用与回答。无模型密钥时明确显示本地摘录；模型 Token 来自服务端 usage，不以字数代替。
- 可观测：`/#/observability`。总览、构建、Agent、对话、用量、异常读取服务端日志。新链路为 captured、外部执行器上报为 reported、旧查询记录为 historical；缺失的内部证据不补造。
- 评测集：`/#/evaluations`。从对话或 Agent 日志手动回流 Goodcase / Badcase，保存不可变执行快照；支持多集合、标注、筛选、批量归集和 JSON 导出。相同 run / trace 并发回流只创建一个 Case，版本冲突不会覆盖他人标注。

运行详情“执行实录”展示公开 Plan、模型请求 / 响应、工具、Skill、上下文与 Harness 事件。实际采集了源码的节点可展开代码和行号解释；未采集的内容明确提示。运行中的节点不伪造完成事件。

API 模式中的评测集在 PostgreSQL 保存，跨浏览器共享；演示模式继续使用 `zhihuitai:evaluations:v1` 的 localStorage，已有原型 Case 不删除、不自动混入真实集合。

## 仍属原型的范围

模型配置 / OCR 管理、应用场景页、部分知识库编辑及检索测试设置仍按现有原型工作。九种分块策略的前端预览不代表已接通九种后端算法。API 模式隐藏演示观测设置；异常处理状态与备注仍只在页面会话内，页面会明确说明。计价未配置时显示待核价，尚无自动评测运行与通用 Agent 执行器。

管理员可访问评测集和全部观测页面；知识库管理人员查看构建记录；使用者使用对话。Hash 路由支持直接打开日志和 Case，缺失来源日志不影响已保存快照。
