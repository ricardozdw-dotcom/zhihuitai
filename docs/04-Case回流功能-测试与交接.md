# Case 回流功能：测试与交接

## 本机测试入口

- 前端：<http://127.0.0.1:43123/#/evaluations>，选择管理员角色。
- 日志：<http://127.0.0.1:43123/#/observability/conversations>。
- 在线对话：<http://127.0.0.1:43123/#/chat>。
- 后端接口文档：<http://127.0.0.1:43180/docs>。

本轮实现的是线上日志到人工评测集的完整流程，包括实际问答 / 构建日志采集、外部 Agent 执行记录接入、人工回流、标注和归集。没有将其他原型页面一并宣称为完整后端能力。

## 建议验收步骤

1. 在“在线对话”选择已有知识库并提问，等待回答完成。
2. 打开“可观测 → 对话日志”，找到刚才的问题，进入实录查看完整检索命中、资料装配和生成结果。提供了实际源码的节点可展开代码和解释；未记录的代码明确提示缺失。
3. 点击“回流 Case”，新建或选择评测集，选择 Goodcase / Badcase / 待标注，填写原因、期望答案、标签并保存。
4. 在“评测集”查看样本、筛选分类，进入 Case 修改标注并保存。打开“执行快照”核对输入、输出和节点；标注不会改变这些内容。
5. 对同一日志再次回流，加入另一个评测集；全部 Case 数量不重复增加，原标注保留。
6. 勾选多个 Case，批量加入目标集合；刷新页面或在另一浏览器进入，看到相同服务端数据。
7. 按分类 / 时间 / 关键词筛选后导出 JSON，文件包含当前筛选的样本、标注、完整快照及关联集合信息。

为人工验收保留了“功能验收 · 每日 Case”“功能验收 · 回归基准”集合。它们来自本轮实际页面操作，样本明确写有“功能验收”。原先浏览器中的原型演示数据未删除，也不自动混入服务端集合。

## Agent / Harness 接入

外部执行器调用 `POST /api/observability/runs` 上报完整记录，格式见 Swagger 的 RunIn。唯一 run / trace，带时区的 startedAt、根状态、节点父子关系及每个节点的输入、输出、事件均受校验。运行中按顺序重新上报全量记录，保留已完成节点；结束后原记录不可修改。同一终态内容重传幂等。

公开计划放在模型节点 `output.public_plan`；模型请求完整放在 `input.messages` / `input.tools`，不要只传摘要。上下文放在 `context`；工具、Skill、Harness 分别作为对应类型节点，异常使用 error / issue / issueNode。执行代码放在 executionSource（path、revision、language、code、annotations），解释标注行号。

系统展示的是执行器实际提供的公开证据。平台不执行上报代码，不补造模型内部思考、未采集的早期轮次或局部变量。当前项目尚未启动通用自主 Agent 执行器，Agent 页面会等待真实运行上报；接入协议与回流流程已经可用。

## 已验证的关键行为

2026-10-28 自测结果：后端 7 项通过，前端 14 项通过，生产构建通过。浏览器完成 Goodcase、Badcase 各一条真实请求的回流，以及多集合归属、批量归集、标注、筛选、刷新和导出。测试输出 JSON 校验包含完整快照及有效集合归属。供应商真实密钥与账单未联调。

- 临时独立 PostgreSQL 数据库内执行原有 API / 元数据测试与新增链路测试，不覆盖业务数据库。
- 导入文本文件 → 构建过程 → 检索 → SSE 问答 → 实际节点记录 → 回流快照。
- 测试模型回调返回的 Token 被采集；真实云模型凭据未配置，不将测试回调当作供应商联调成功。
- 同一来源 5 个并发回流请求仅创建一份 Case；重复回流只补充集合归属。
- 同名集合、空白名称、无效归属、错误 Trace、非终态回流、循环调用树被拒绝。
- 标注版本冲突返回 409，不覆盖已更新内容；数据库拒绝改写源快照。
- 批量归集中出现无效 Case 时整批不写入。
- 源运行删除后，另一独立客户端仍能读取已保存快照。
- 工具 / 模型异常、损坏 PDF 的失败构建可查看；配置密钥及结构化凭据字段脱敏。
- 浏览器验证新建集合、从实际对话回流、内联新建集合、多归属、修改标注、快照保持和导出。

## 当前边界

- 未配置云模型密钥时，问答是明确标记的本地原文摘录；不产生外部模型 Token。配置 `LLM_*` 后走 LangChain 模型链；`EMBEDDING_*` 控制向量服务。
- Token 只在供应商返回 usage 时显示为实测，未知不当作零；分项上下文 Token 是字符估算。未配置单价的云调用费用为“待核价”，不是正式账单。
- 不含自动评分 / 批量评测运行、通用 Agent 执行器、登录鉴权和自动日志清理。本轮没有扩充 Word / OCR / 表格解析器、九种后端分块策略或模型配置管理界面，这些仍按既有后端支持范围。
- 观测设置和异常处理备注仍是原型交互，API 模式隐藏观测设置；异常备注需留意页面的会话内状态说明。真实日志与评测集已经服务端持久化。
- 评测集 V1 加载当前样本全集，观测列表 API 提供分页、前端逐页读取；大规模使用需要后续加入服务端筛选、摘要列表和快照按需加载。

## 重启

先确保 PostgreSQL + pgvector 运行。在 backend 目录执行 `.venv/bin/alembic upgrade head`，再执行 `.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 43180`。前端 `.env.local` 设置 `VITE_USE_API=true`，在 frontend 目录执行 `npm run dev`。

前端预览已经切回项目的 frontend 源目录；不再依赖临时副本。技术选择与接口说明见 `03-线上Case回流与真实日志-实施方案.md`。
